(pc=0), before any probe instruction runs. Walking the 8191 padding
instructions sequentially then costs 10303 more: 8191 probe instructions plus
64 timer slices (~33 kernel instructions each, clock_interrupt_count = 64).
The discriminating probe's `b 32768` count of 963182 is therefore only 6 above
this load-only baseline, which rules out sequential execution of the 8188
padding instructions (~10.3k instructions would have been needed) and shows the
~963k is the input/load path rather than jump cost. The specific kernel path
behind that load cost is not root-caused here (hypothesis: page mapping /
zero-fill work); flagged for Front 2 and it does not affect the JMPR conclusion.
